## Detailed Findings

### [WARNING] `api/index.ts:25` - CORS Wildcard Origin with Credentials Header (Resolved ✅)
- **Category**: Security / Spec Alignment (W3C CORS Specification)
- **Description**: 
  In `api/index.ts`, when `env.ALLOWED_DOMAIN` is default (`*`), `allowOrigin` is set to `"*"`. Setting `Access-Control-Allow-Credentials: true` unconditionally violates W3C Fetch/CORS rules when origin is wildcard `*`.
- **Remediation**:
  `Access-Control-Allow-Credentials: true` is now conditionally attached only when `allowOrigin !== "*"`.
