            REST API 接口契约规范
          

          

            响应格式统一遵循 { code: 200, message: "...", data: ... } 标准契约
          

        

        
      


      

        

          
            

              端点 Endpoint
              方法 Method
              核心参数 Parameters
              用途 Description
            

          
          
            

              /match
              GET
              id (必填), br (选填), server (选填)
              多音源智能解灰，返回可播放直链及元数据
            

            

              /ncmget
              GET
              id (必填), br (选填)
              获取网易云官方原始高码率音频直链
            

            

              /search
              GET
              name (必填), source (选填), count, page
              跨平台多音源歌曲与歌手列表检索
            

            

              /playlist/:id
              GET
              :id 路径参数 (歌单或专辑 ID)
              批量提取歌单中包含的全部歌曲 ID 列表
            

            

              /lyric
              GET
              id (必填), source (选填)
              获取原版 LRC 歌词与逐行对照翻译歌词
            

            

              /pic 或 /picture
              GET
              id (必填), size (选填: 300/500)
              获取高清专辑封面图 URL
            

            

              /health
              GET
              verbose (选填: true)
              服务健康检查、内存指标与 LRU 缓存统计
