API Contract

REST API 接口契约规范

响应格式统一遵循 { code: 200, message: "...", data: ... }

端点方法参数用途
/matchGETid, server, br多音源智能解灰，返回直链
/playlist/:idGET:id, limit, idsOnly批量解析网易云歌单曲目与元数据（支持分块并发完整获取）
/ncmgetGETid, br网易云官方高码率直链
/searchGETname, source, count, page跨平台多音源歌曲与歌手检索
/lyricGETid, sourceLRC 逐行同步歌词与翻译
/picGETid, source, size高清专辑封面图获取
/healthGETverbose服务健康检查、内存占用与缓存统计
/api/monitor/dataGETpage, limit, path, status实时遥测统计与调用明细日志
